Watchirr
GitHub Get started

Self-hosted · Jellyfin households

One watchlist. Coverage before acquire.

Search, check streaming coverage, acquire into Radarr/Sonarr only when needed, and track watched — in a single app. Finite disk is not wasted on what you can already stream.

Run with Docker View on GitHub

What it does

  • Search movies and TV (TMDB), with Discover rails when the query is empty
  • Watchlist shared by the household — still to watch, coming in, watched
  • Streaming coverage — checks your paid subscription services before acquiring
  • Acquire into Radarr or Sonarr only when coverage is missing
  • Watched from Jellyfin playback progress, or mark by hand
  • Library Import — one-shot Import to Watchlist from Radarr / Sonarr (Settings)
  • Watched Import — one-shot Import Watched from Jellyfin progress (Settings)

Quick start

  1. 1

    Pull the image

    docker pull ghcr.io/watchirr/watchirr:latest

    Prefer a pin for production: ghcr.io/watchirr/watchirr:v1.0.4 or :v1.

  2. 2

    Deploy the stack

    Docker Compose or Portainer Stacks — same image on port 3001, SQLite at ./data/watchirr.db. Compose example and portainer-stack.yml live in the repo. 

    docker compose -f docker-compose.example.yml up -d
  3. 3

    Open the app

    Visit http://localhost:3001, create the Admin on first run (/setup), then configure TMDB / *arr / Jellyfin in Settings.

Full durability, Postgres, and reverse-proxy notes: docs/self-host.md.
